# Sales Data Analysis — Python & Pandas

A data analysis project using **Python, Pandas, NumPy, Matplotlib and Seaborn** to clean, explore, analyze and visualize customer sales data.

## Project Overview

The notebook covers:

- Data loading and initial exploration
- Dataset shape, information and descriptive statistics
- Duplicate and missing-value handling
- Data cleaning and value transformation
- Customer analysis by gender, age group, marital status, state and occupation
- Product-category and sales analysis
- Data visualization using Matplotlib and Seaborn
- Correlation analysis of numerical variables
- Final business-oriented observations

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning

The analysis includes:

- Checking and removing duplicate records
- Removing columns containing only missing values
- Handling rows with missing values
- Converting coded gender and marital-status values into readable categories

## Key Analysis

The notebook investigates questions such as:

- Customer distribution by gender
- Sales by age group
- Top states by total sales
- Sales across product categories
- Relationship between age and amount spent
- Gender-wise sales comparison
- Product-category distribution by gender
- Correlation between Age, Orders and Amount
- Sales across age groups and product categories

## Visualizations

The project includes bar charts, count plots, regression plots, box plots and a correlation heatmap to communicate the analysis visually.

## Key Observations

The notebook's analysis indicates that:

- Female customers account for a substantially larger share of customers and total spending than male customers.
- The **26–35 age group** has the highest total sales among the age groups analyzed.
- Uttar Pradesh, Maharashtra, Karnataka, Delhi and Madhya Pradesh appear among the highest-sales states.
- Clothing & Apparel has the highest number of orders in the analysis.
- The notebook also examines the interaction between age group, product category, gender and marital status.

## Files

- `sales_data_analysis.ipynb` — Jupyter Notebook containing the complete analysis
